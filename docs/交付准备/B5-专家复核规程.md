# B5 · 专家复核规程

> **用途**：明确「**谁签、签什么、能否对外具名**」——这是「**专家复核作为交付增值项**」的落地规则。
> **一句话**：**内部复核是纪律（必做、不对外）；专家复核是增值（可选、具名需授权）。**

## 一、两种复核（不可混为一谈）

| 类型 | 谁做 | 做什么 | 是否另行收费 | 是否具名 |
| --- | --- | --- | --- | --- |
| **内部质量复核**（**必做**） | 交付团队内部复核人 | 抽检一致性、溯源完整性、结论与事实是否对应 | 否（成本内化） | **不对外** |
| **专家复核**（可选增值） | 外部 / 内部资深顾问 | 对重点报告的人工复核与背书 | **是**（口径见《商业模式与验证》） | **须专家书面同意** |

## 二、内部质量复核（必做 · 不通过不得交付）

| # | 复核项 | 通过标准 |
| --- | --- | --- |
| 1 | **溯源完整性** | 报告中**每条结论**均可定位到具体文档位置 |
| 2 | **抽检一致性** | 抽检 ≥20%（**含全部低置信项**），一致率 **≥95%** |
| 3 | **硬三类可对账性** | 每条金额可被客户**独立复算**（口径 + 计算式齐备） |
| 4 | **误判排除** | 试点 / 备用 / 灾备 / 合规留存**均已由客户确认排除** |
| 5 | **口径唯一** | 同一指标全文**只有一个口径**（防"三套阈值并存"的历史问题） |
| 6 | **措辞纪律** | 无「无贡献 / 落后 / 需要激活」类**负面定性**（2.11 ① 邀请式措辞） |

**签署**：交付人 __________　复核人 __________　日期 __________（**双签**）

## 三、专家复核（可选）

| 项 | 约定 |
| --- | --- |
| **触发** | 客户主动购买 / 高价值报告 / 高合规行业 |
| **范围** | 重点章节：机会排序、ROI 假设、处置建议（**不重做事实层**） |
| **输出** | 复核意见（附于报告附录，标注「**专家意见不改变事实层**」） |
| **具名规则** | **必须专家本人书面同意**；不同意则署「外部资深顾问（匿名）」 |
| **责任边界** | 专家复核**不改变事实层与可对账金额**，只影响「判断层」的建议权重 |
| **计价** | 按次 / 按报告（**不按人天**——避免滑向人力咨询，见《商业模式与验证》红线） |

## 四、红线（违反即违规）

| # | 红线 | 为什么 |
| --- | --- | --- |
| 1 | **不得为促成交易而宣称「某专家背书」** | 虚假宣传 |
| 2 | **专家意见与系统结论冲突时，如实并列呈现** | 不以专家意见覆盖事实（事实优先） |
| 3 | **专家署名未获书面同意即使用** | 侵权 |
| 4 | **专家复核不得成为"事实层的遮羞布"** | 事实缺失就是缺失，靠专家意见补不了溯源 |
